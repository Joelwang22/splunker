# Splunk Helper
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Static HTML, CSS and JavaScript. The user approved a local HTML helper and requested GitHub Pages hosting in Joelwang22/splunker. No backend, account, build dependency, or Splunk connection.
## Users
A learner who completed the Buttercup Games Splunk tutorials and wants to independently compose searches and output tables/charts, rather than memorize command definitions.
## Product Purpose
Turn an investigation question into an understandable classic SPL pipeline. Explain changes, demonstrate results on synthetic events, and develop independent skills with worked recipes and exercises.
## Capabilities and Constraints
Guided source/time selection, explicit Boolean filter groups, aggregations, calculated columns, output shaping, editable SPL, local saved searches, command reference, recipes, exercises. Examples are illustrative. Arbitrary SPL is not executed. Public GitHub Pages repository target: Joelwang22/splunker. Preserve compatibility with the classic SPL used in the user's Splunk 7.3 lab.
## Product Principles
Show the query and its purpose together. Distinguish event filters from summary filters. Never imply an illustrative preview queried Splunk. Make every interaction usable with keyboard and on mobile. Store only user-created local drafts, with no telemetry.
